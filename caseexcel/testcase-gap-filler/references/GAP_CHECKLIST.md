# 测试用例遗漏检查清单

## 使用说明
本清单用于指导 Agent 在对比需求与现有用例时，系统性检查遗漏点。每发现一项遗漏，直接触发补全用例生成。

---

## 一、功能覆盖检查

### 1.1 模块级检查
- [ ] 需求中的每个一级模块是否都有对应用例
- [ ] 需求中的每个二级功能点是否都有对应用例
- [ ] 需求中的每个具体功能是否都有对应用例

### 1.2 功能子项检查（常见遗漏点）
以下功能常作为"主功能"的附属项被遗漏：
- [ ] 列表功能：是否包含排序、分页、筛选、导出子项
- [ ] 导入功能：是否包含模板下载、数据校验、错误报告、部分成功子项
- [ ] 审批功能：是否包含提交、撤回、转交、驳回、催办子项
- [ ] 通知功能：是否包含发送、重发、退订、模板管理子项
- [ ] 配置功能：是否包含保存、重置、导入、导出、校验子项

## 二、异常场景检查清单

### 2.1 输入异常
| 检查项 | 触发条件 | 补全用例示例 |
|--------|----------|--------------|
| 空值/Null | 必填字段不输入 | 用户名字段为空提交 |
| 超长输入 | 超过最大长度 | 用户名输入101个字符（限制100） |
| 非法字符 | 特殊符号、emoji | 用户名输入"&lt;&gt;script"、emoji |
| 格式错误 | 不符合格式要求 | 邮箱输入"abc"（无@） |
| 数据类型错误 | 数字字段输入字符串 | 年龄字段输入"abc" |
| 注入攻击 | SQL注入、XSS、命令注入 | 输入"' OR '1'='1"、"&lt;&lt;script&gt;" |

### 2.2 权限异常
| 检查项 | 触发条件 | 补全用例示例 |
|--------|----------|--------------|
| 未登录访问 | 未登录直接访问需鉴权页面 | 未登录访问订单管理页 |

| 角色不足 | 低权限角色执行高权限操作 | 普通用户执行管理员删除操作 |
| Token失效 | 使用过期/伪造Token | 使用过期Token调用API |

### 2.3 状态异常
| 检查项 | 触发条件 | 补全用例示例 |
|--------|----------|--------------|
| 非法状态操作 | 对非预期状态的数据操作 | 对已取消订单再次支付 |
| 并发冲突 | 多用户同时修改同一数据 | A编辑时B同时保存 |
| 重复操作 | 重复提交/支付/发送 | 快速双击提交按钮 |
| 状态回退 | 终态数据尝试回退 | 已完结订单尝试取消 |

### 2.4 依赖异常
| 检查项 | 触发条件 | 补全用例示例 |

| 下游超时 | 第三方接口超时 | 支付接口超时后的处理 |

| 网络中断 | 断网/弱网场景 | 上传过程中断网 |
| 数据库异常 | 连接失败、死锁 | 数据库连接池耗尽 |

### 2.5 资源异常
| 检查项 | 触发条件 | 补全用例示例 |
|--------|----------|--------------|
| 存储满 | 磁盘空间不足 | 上传文件时磁盘已满 |

| 并发超限 | 超过最大并发数 | 超过1000并发访问 |
| 限流触发 | 频率限制 | 1秒内发送100次请求 |

### 2.6 业务异常
| 检查项 | 触发条件 | 补全用例示例 |
|--------|----------|--------------|
| 重复支付 | 同一订单多次支付 | 订单已支付后再次发起支付 |

| 超出限额 | 超过业务限制 | 超过单日转账限额 |
| 数据不存在 | 操作已删除数据 | 访问已删除的订单 |

## 三、边界场景检查清单

### 3.1 数值边界
| 检查项 | 边界值 | 补全用例示例 |
|--------|--------|--------------|
| 最小值-1 | 0（要求&gt;0） | 商品数量输入0 |
| 最小值 | 1 | 商品数量输入1 |
| 正常值 | 中间值 | 商品数量输入50 |
| 最大值 | 上限值 | 商品数量输入100（上限100） |
| 最大值+1 | 上限+1 | 商品数量输入101 |
| 负数 | 负值 | 商品数量输入-1 |
| 极大值 | 超出合理范围 | 金额输入999999999999 |

### 3.2 长度边界
| 检查项 | 边界值 | 补全用例示例 |
|--------|--------|--------------|
| 空字符串 | "" | 搜索关键词为空 |
| 1个字符 | "a" | 用户名输入1个字符 |
| 正常长度 | 中间值 | 用户名输入10个字符 |
| 最大长度 | 上限值 | 用户名输入20个字符（上限20） |
| 最大长度+1 | 上限+1 | 用户名输入21个字符 |

### 3.3 数量边界
| 检查项 | 边界值 | 补全用例示例 |
|--------|--------|--------------|
| 0条 | 空列表 | 查询结果为空 |
| 1条 | 单条数据 | 列表只有1条记录 |
| 正常条数 | 中间值 | 列表有50条记录 |
| 最大条数 | 上限值 | 批量导入100条（上限100） |
| 最大条数+1 | 上限+1 | 批量导入101条 |

### 3.4 时间边界
| 检查项 | 边界值 | 补全用例示例 |

| 起始边界 | 00:00:00 | 定时任务在零点触发 |

### 3.5 集合边界
| 检查项 | 边界值 | 补全用例示例 |

### 3.6 状态边界
| 检查项 | 边界值 | 补全用例示例 |
|--------|--------|--------------|

| 终态 | 已完成 | 已完成的订单尝试退款 |

## 五、需求关键词→补全用例映射速查

以下关键词在需求中出现时，必须触发对应补全用例生成：

| 需求关键词 | 必须补全的用例 | 类型 |
|-----------|---------------|------|
| "必填"、"不能为空" | 空值提交 | 异常 |
| "最多X字符" | 空、1、X、X+1 | 边界 |
| "仅支持数字/字母" | 中文、符号、emoji、空格 | 异常+边界 |
| "批量" | 0条、1条、上限、上限+1、部分失败 | 边界+异常 |
| "导入/导出" | 空文件、错误格式、超大文件、编码错误 | 异常+边界 |
| "搜索" | 无结果、特殊字符、超长关键词、SQL注入 | 异常+边界 |
| "编辑" | 并发编辑、编辑取消、脏数据 | 异常 |
| "定时/自动" | 重叠执行、失败重试、幂等性 | 异常+边界 |
| "金额/价格" | 0、负数、极大值、精度边界 | 边界 |
| "发送" | 发送失败、重复发送、退订 | 异常 |
| "响应时间&lt;&lt;X秒" | 压测场景、超时场景 | 性能 |
| "权限/角色" | 未登录、越权、角色不足 | 异常+安全 |
| "状态/流程" | 非法跳转、终态操作、回退 | 异常 |
| "删除" | 删除后访问、级联删除、恢复 | 异常 |
| "关联" | 依赖缺失、循环依赖 | 异常 |
| "缓存" | 缓存失效、缓存穿透、缓存雪崩 | 异常 |
| "消息队列" | 消息丢失、重复消费、顺序错乱 | 异常 |
