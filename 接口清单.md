# 2. 智能体

## 2.1 工作流

### 2.1.1 会话

#### 2.1.1.1 创建会话

**请求地址：**/conversation/create

**请求方式**：post



* **Header参数**

| 参数           | 类型     | 是否必填 | 描述                     | 示例               |
| ------------ | ------ | ---- | ---------------------- | ---------------- |
| Content-Type | string | Y    | 固定值 "application/json" | application/json |



* **请求参数**

| 参数         | 类型   | 必填 | 描述      |
| ---------- | ---- | -- | ------- |
| agentId    | Long | Y  | 智能体id   |
| identityId | Long | N  | 用户的唯一标识 |

* **响应参数**

| 参数            | 类型      | 描述                      |
| ------------- | ------- | ----------------------- |
| errCode       | Integer | 状态码，成功：0；失败：异常错误码       |
| errMessage    | String  | 状态消息，成功：success；失败：异常提示 |
| success       | Boolean | 是否成功，成功：true；失败：false   |
| data          | Object  | 返回数据                    |
|     sessionId | String  | 会话Id                    |

* **请求示例**

```yaml
{
    "agentId": 2039"
}
```



* **响应示例**

```json
{
    "success": true,
    "errCode": 0,
    "errMessage": null,
    "data": {
        "sessionId": "cc5dcacb-b731-481a-974a-aa81764b7990-1765273133898-2039"
    }
}
```



#### 2.1.1.2 查询会话记录

**请求方式**：get



* **Header参数**

| 参数           | 类型     | 是否必填 | 描述                          | 示例                    |
| ------------ | ------ | ---- | --------------------------- | --------------------- |
| Content-Type | string | Y    | 固定值 "x-www-form-urlencoded" | x-www-form-urlencoded |





* **请求参数**

| 参数         | 类型     | 必填 | 描述                               |

| endTime    | String | N  | 范围查询，结束时间。格式：yyyy-MM-dd HH:mm:ss |
| identityId | String | N  | 用户的唯一标识                          |

* **响应参数**

| --------------- | -------------- | ------------------ |
| pageNum         | Integer        | 当前分页               |
| pageSize        | Integer        | 分页数                |
| totalPages      | Integer        | 总页数                |
| totalSize       | Integer        | 总条数                |
| data            | Array\<Object> | 会话列表集合             |
| title           | String         | 会话标题名称             |
| sessionId       | String         | 会话id               |

| startTime       | String         | 会话开始时间             |
| endTime         | String         | 会话结束时间             |
| sessionDuration | Long           | 会话时长（秒)            |
| errorCode       | Integer        | 调用状态码。             |
| errorMessage    | String         | 状态信息。              |

#### 2.1.1.4 删除会话

**请求地址：/sessions/record/delete**

**请求方式**：get

* **Header参数**

| 参数           | 类型     | 是否必填 | 描述                          | 示例                    |
| ------------ | ------ | ---- | --------------------------- | --------------------- |
| Content-Type | string | Y    | 固定值 "x-www-form-urlencoded" | x-www-form-urlencoded |

* 请求参数

| 参数名            | 类型      | 必填 | 说明                       |
| -------------- | ------- | -- | ------------------------ |
| agentId        | Long    | 是  | 智能体 ID                   |
| workflowId     | Long    | 否  | 工作流 ID                   |
| sessionId      | String  | 否  | 会话 ID                    |
| exeType        | Integer | 否  | 执行类型，`1` 表示调试，`2` 表示 API |
| agentVersionId | Long    | 否  | 智能体版本 ID                 |



* 请求示例



```http
GET /sessions/record/delete?agentId=10001&workflowId=20001&sessionId=session_123&exeType=1&agentVersionId=30001
```



* 响应说明

| 字段   | 类型               | 说明                |
| ---- | ---------------- | ----------------- |
| code | String / Integer | 响应码，成功时通常为业务成功码   |
| msg  | String           | 响应消息              |
| data | Integer          | 删除结果，通常为删除成功的数据条数 |

* 响应示例

```json
{
  "code": 200,
  "msg": "success",
  "data": 1
}
```

**响应说明 :**

3) action=rollback 会回滚到运行前的状态，丢弃本次运行的所有更改

4) 当 wait=true 时，接口会阻塞直到任务完全停止，最长等待时间取决于任务当前执行状态

##### 1.&#x20;**&#x20;入站消息协议（client → server）**

> 一个 WebSocket 连接上可以发送多次 run 请求（多轮 / 并发 run），每条消息驱动一次 `runs.stream` 调用。

###### 2.2.4.3.1.1 通用消息结构

所有入站消息必须是 JSON 对象，当前仅支持一种操作：

```typescript
type ClifeWsIncomingMessage = {
  op: "run"
  assistant_id: string    // 必填；LangGraph graph 名或 assistant UUID，如 lead_agent
  input: object           // 必填；LangGraph runs.stream 的 input，对应 HTTP 的 body.input
  config?: object         // 可选；LangGraph runs.stream 的 config
  context?: {
    langgraph?: object    // 可选；直接传给 LangGraph 的 context
    // clife?: object     // 预留，不参与协议，不影响当前实现
  }
}
```

###### 2.2.4.3.1.2 新建线程场景

* URL：`/agentic/channe/threads/clife/runs/stream/ws`

* Body 示例（APIFOX 可以直接复制）：

```json
{
  "op": "run",
  "run_id": "demo-run-001",           // 客户自定义；不填则后端生成
  "assistant_id": "lead_agent",       // 必须是 LangGraph 已注册的 graph/assistant
  "input": {
    "messages": [
      { "role": "user", "content": "帮我想一个产品名字" }
    ]
  },
  "config": {
    "configurable": {}
  },
  "context": {
    "langgraph": {
      "metadata": {
        "source": "clife_ws_demo",
        "biz_scene": "clife-copilot"
      }
    }
  }
}
```

后端行为：

1. 发现没有 `thread_id`（URL & body 都无），会调用 `client.threads.create()` 创建新线程；

2. 将新 `thread_id` 写入：

   * WebSocket 返回帧中的 `thread_id`

   * 传入 LangGraph 的 `context`：

     * `context.thread_id`

     * `context.metadata.thread_id`（如果 metadata 是个对象）
